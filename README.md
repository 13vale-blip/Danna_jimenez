# S.I. Registro y Control de Inasistencias

Evidencia **GA7-220501096-AA4-EV03** - Componente front-end del proyecto formativo.

Sistema de información web (responsive) de la Institución Educativa
"Aprendices del Saber". Este módulo corresponde a **Inasistencias**
(formulario de registro).

## Estructura

```
index.html    -> estructura de la página
estilos.css   -> estilos y diseño responsive (@media 600px)
script.js     -> menú hamburguesa, fecha automática y registro del formulario
Imagenes/     -> recursos gráficos
```

## Cómo verlo

Abrir `index.html` en el navegador. Para ver la versión móvil, reducir el
ancho de la ventana a 600px o menos (o usar las herramientas de desarrollador, F12).

## Qué hace JavaScript

- Muestra y oculta el menú con el botón hamburguesa en pantallas pequeñas.
- Llena automáticamente la fecha y hora actual en el formulario.
- Al enviar el formulario, muestra un mensaje de confirmación sin recargar la página.
